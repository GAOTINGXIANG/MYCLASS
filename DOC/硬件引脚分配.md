# MYCLASS 硬件引脚分配与初始化说明

- MCU：STM32F407VGT6（LQFP100）
- 工具链：STM32CubeMX 6.16.0 / STM32Cube FW_F4 V1.28.3，MDK-ARM V5.32
- 系统时钟：HSE 8 MHz（板载晶振，PH0/PH1）→ PLL（M=4, N=168, P=2, Q=4）→ SYSCLK 168 MHz
  - AHB 168 MHz，APB1 42 MHz（定时器 84 MHz），APB2 84 MHz，Flash 5WS
- RTOS：FreeRTOS 10.3.1，CMSIS-RTOS v2 封装，1 个 `defaultTask`（Normal，128 words 栈）

## 二、外设配置摘要

| 外设 | 关键配置 | 备注 |
| --- | --- | --- |
| SPI1 | Master，1-line（Transmit Only），8 bit，CPOL=Low / CPHA=1Edge（Mode 0），MSB first，NSS 软件，预分频 2 → 42 Mbit/s | GC9A01 只写，1-line 模式正确 |
| ADC1 | 12 bit，PCLK2/4 = 21 MHz，**扫描开启、2 个转换、连续转换**，采样时间 84 cycles；DMA2_Stream0 / Channel 0，循环模式，半字对齐 | 采样率约 110 kHz（每通道 4.6 μs） |
| DMA | DMA2_Stream0 用于 ADC1，循环模式，中断优先级 5 | `MX_DMA_Init()` 在 `MX_ADC1_Init()` 之前调用 |
| TIM4 | PSC = 83 → **1 MHz 计数（1 μs 分辨率）**，ARR = 65535（65.5 ms 满量程）；CH2 输入捕获（直连 TI2、上升沿、无预分频、**滤波 8**） | 距离 ≈ 捕获值 × 0.017 cm，无需统计溢出 |
| NVIC | 优先级分组 4；SysTick 15，TIM4 5，DMA2_Stream0 5（configMAX_SYSCALL = 5） | 中断优先级数值不可 < 5，否则不能调用 FromISR API |
| FreeRTOS | heap_4，总堆 15360 B，tick 1000 Hz，抢占式；`defaultTask` 栈 512 B | 栈偏小，复杂任务建议 256 words 起 |

## 三、已修正项（对照初版检查）

1. ADC1 已增加第二通道（按实际硬件为 IN13 / PC3，Rank 2）、打开扫描、采样时间由 3 cycles 改为 84 cycles。
2. SPI1 由全双工 2 线改为 1-line 发送模式，与 PA5/PA7 的引脚模式一致。
3. TIM4 预分频 0 → 83（84 MHz → 1 MHz），不再需要软件统计溢出；捕获滤波 0 → 8。
4. 时钟源 HSI → HSE，并按板上 8 MHz 晶振重新计算：PLLM = 4（VCO 输入 2 MHz）、PLLN = 168、PLLP = 2 → 168 MHz；`HSE_VALUE` 已是 8000000。
5. 另加了 ADC + DMA2_Stream0 循环采集。

## 四、仍需注意（使用层面）

1. **ADC 现在是"扫描 + 连续转换 + DMA 循环"**：必须用
   `HAL_ADC_Start_DMA(&hadc1, (uint32_t *)js_buf, 2)`（长度 = 转换次数 2，不是字节数），
   然后从 `uint16_t js_buf[2]` 读取：`js_buf[0]` = VRy(IN11/PC1)、`js_buf[1]` = VRx(IN13/PC3)。
   不要再混用 `HAL_ADC_Start` + `HAL_ADC_PollForConversion` + `HAL_ADC_GetValue`，否则会读到两通道交替的值。
2. **ADC 校准**：本工程 HAL 包（FW_F4 1.28.3）的 ADC 驱动里**没有** `HAL_ADCEx_Calibration_Start`，照抄旧例程会编译报错；如需自校准只能直接操作 `ADC_CR2.CAL` 位，一般可不做。
3. **DMA Continuous Requests 已改为 Enable**，与连续转换模式匹配。
4. **DHT11**：PC6 内部上拉约 40 kΩ 偏弱，数据线建议外加 4.7~10 kΩ 上拉；读取前需切为输入，并关中断保护 μs 级时序；FreeRTOS 中不要用 `HAL_Delay`。
5. **电平**：PB7（Echo）与 PC6（DHT11）为 FT 引脚，可接 5 V 信号；其余引脚不要接 5 V。
6. **有源蜂鸣器**：PB11 直驱电流不足，建议经三极管/MOS 管驱动。
7. **SPI 速率 42 MHz 偏高**：GC9A01 手册写时序上限约 10~20 MHz 量级（实际模块多能跑到 40 MHz 以上）。若出现花屏/白屏，把预分频改为 4（21 MHz）验证。
8. **PLLQ = 4**：USB 时钟只有 84 MHz，若以后用 USB 需改为 7；当前不用 USB 无影响。
9. **GC9A01 显存**：240×240×2 B = 115200 B，超过 SRAM1 的 112 KB，且 SRAM2/CCM 地址不连续，无法做整屏 framebuffer，需分块刷屏或直接绘制。
10. **HARDWARE 目录**：当前为空，未加入 Keil 的 Group 与 Include Path，放入驱动后需手动添加。
11. **栈溢出检测**：`FreeRTOSConfig.h` 未开启 `configCHECK_FOR_STACK_OVERFLOW`，调试阶段建议设为 2。
