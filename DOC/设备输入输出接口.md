# 设备输入输出接口汇总

平台：STM32F407 @ 168MHz，HAL + FreeRTOS（CMSIS-RTOS2），Keil AC5。
所有驱动位于 `HARDWARE/`，LVGL 适配层位于 `LVGL_BSP/`，演示程序位于 `DEMO/`。
除特殊说明外，初始化函数均需在对应 `MX_*_Init()` 之后调用。

## 1. 输出设备

### 1.1 圆形 LCD（GC9A01，240x240）

SPI1 + DMA2 Stream3，21Mbit/s；圆心 (120,120)，半径 120，四角不可见。

| 文件 | 接口 |
| --- | --- |
| `gc9a01.h` | `gc9a01_init()`、`gc9a01_set_window()`、`gc9a01_draw_pixel()`、`gc9a01_fill_rect()`、`gc9a01_fill_circle()`、`gc9a01_draw_string()`、`gc9a01_printf()`、字号切换 `gc9a01_set_font_size()`（8x16 / 12x24 / 16x32） |
| `lcd_spi.h` | `lcd_spi_write_blocking()`（阻塞）、`lcd_spi_write_dma()`（DMA + 忙标志）、`lcd_spi_cs_high()` |
| LVGL | `lv_port_disp_init()`（LVGL_BSP），双缓冲 240x40x2，DMA 刷新 |

> LVGL 接管屏幕后不要再直接调 gc9a01 绘图函数，避免打断 DMA。

### 1.2 LED x6

PC9 / PC12 / PC11 / PD0 / PA8 / PC7，高电平点亮（`LED_ACTIVE_LEVEL`）。

`led.h`：`led_init()`、`led_on/off/toggle(id)`、`led_write(id, on)`、`led_all(on)`。

### 1.3 有源蜂鸣器

PB12（BEEP_Y），高电平响（`BEEP_ACTIVE_LEVEL`）。

`beep.h`：`beep_init()`、`beep_on/off/toggle()`、`beep_write(on)`、`beep(ms)`（阻塞鸣叫）。

## 2. 输入设备

### 2.1 摇杆（双轴电位器）

VRy=PC1 (ADC1_IN11)、VRx=PC3 (ADC1_IN13)，ADC1 扫描 + DMA 循环，自动持续采样。

`joystick.h`：`joy_init()`（需中位）、`joy_read(&st)`、`joy_get_dir()`、`joy_get_mask()`。
`joy_state_t`：`raw_x/raw_y`（0~4095）、`x/y`（-1000~+1000）、`dir`（8 方向枚举）、`mask`（上下左右位掩码，斜推可组合）。
轴变换宏在 `joystick.c` 头部：`JOY_X_INVERT` / `JOY_Y_INVERT` / `JOY_XY_INVERT` / `JOY_XY_SWAP`，顺序为 交换→翻转→方向计算。

### 2.2 实体按键 x6

KEY1=PC5、KEY2=PB1、KEY3=PE8、KEY4=PE10、JS_KEY=PD9（摇杆按下）、ENCODER_KEY=PD3（编码器按下）；全部上拉输入、按下为低。

`keys.h`：`key_pressed(id)`、`keys_state()`（当前位掩码）、`keys_scan()`（按下沿，取后清零）；消抖 20ms（`KEYS_DEBOUNCE_MS`）。位掩码 `KEY_MASK(KEY_ID_x)`。

### 2.3 旋转编码器

TIM5 编码器接口，A=PA1、B=PA0，TI12 四倍频，32 位计数。

`encoder.h`：`encoder_init()`（清零并启动）、`encoder_count()`（绝对计数）、`encoder_delta()`（距上次调用的增量，会刷新基准）、`encoder_dir()`、`encoder_reset()`。方向反了改头部 `ENCODER_DIR_INVERT`。

## 3. 传感器

### 3.1 DHT11 温湿度

PC6 单总线（开漏+上拉），DWT 微秒时序，阻塞约 5ms，采样间隔 >= 1s。

`dht11.h`：`dht11_init()`、`dht11_read(&data)` → `dht11_data_t{temperature, humidity}`（小数位恒 0）。

### 3.2 HC-SR04 超声波

Trig=PB9、Echo=PB7（TIM4_CH2 输入捕获，1us 分辨率），阻塞最长约 40ms。

`hcsr04.h`：`hcsr04_init()`、`hcsr04_measure_us(&us)`、`hcsr04_measure_cm(&cm)`，状态码 `HCSR04_OK / NO_ECHO / ERROR`。

### 3.3 HMC5883L 磁力计

I2C2：SCL=PB10、SDA=PB11，DRDY=PE14；7 位地址 0x1E，100kHz。
安装方位：模块在板背面、丝印 Y 轴指向屏幕上方（机头）→ `HMC5883L_MOUNT_BACK_Y_UP 1`。
校准：min-max 法（硬铁偏移 + 各轴比例），参数仅存 RAM。

`hmc5883l.h`：
- `hmc5883l_init()`（校验 ID "H43"，8 次平均 / 15Hz / 连续模式）
- `hmc5883l_read(&data)` → `{x, y, z}`（已整理寄存器 X,Z,Y 乱序）
- `hmc5883l_heading_deg10(&data)` → 0~3599（0.1 度，自动应用校准与安装方位）
- `hmc5883l_data_ready()`（DRDY 低 = 就绪）
- 校准：`hmc5883l_calib_reset()` → 反复 `hmc5883l_calib_feed()` → `hmc5883l_calib_finish()`
- 调整宏：`HMC5883L_MAG_DECL_DEG10`（方位偏移，0.1 度）、`HMC5883L_CALIB_MIN_DELTA`

## 4. LVGL 输入映射（LVGL_BSP/lv_port_indev.c）

所有输入绑定同一个默认 `lv_group`：

| 输入 | LVGL 映射 |
| --- | --- |
| 编码器旋转 | `LV_INDEV_TYPE_ENCODER`，焦点移动 |
| ENCODER_KEY | 编码器确认（`lv_port_encoder_key()`，keys.c 强定义） |
| KEY1 / KEY2 | `LV_KEY_PREV` / `LV_KEY_NEXT` |
| KEY3 / JS_KEY | `LV_KEY_ENTER` |
| KEY4 | `LV_KEY_ESC` |
| 摇杆 8 方向 | `LV_KEY_UP/DOWN/LEFT/RIGHT`（KEYPAD） |

demo 内直接读输入时约定：编码器用 `encoder_count()` 绝对值做差、按键用 `keys_scan()` 按下沿，避免与 indev 抢数据。

## 5. 现有演示程序（DEMO/）

| 文件 | 内容 | 操作 |
| --- | --- | --- |
| `demo_encoder` | 边缘圆环 + 编码器驱动小球 | 旋转编码器 |
| `demo_keys` | 6 指示灯对应 6 按键 | 按键点亮 |
| `demo_sensor` | 温湿度 + 距离大字显示 | 自动刷新 |
| `demo_clock` | 模拟表盘 + 数字时间 | 编码器调值，KEY3/JS/ENC 切字段，KEY1/2 微调 |
| `demo_compass` | 旋转刻度盘指南针 | KEY3 开始/结束校准 |

在 `freertos.c` 的 `LVGL_TASK` 中切换启用的 demo。
