# 中文字模生成指南

> 工具：https://lvgl.io/tools/fontconverter
> 目标：生成 **一颗 14px 中文字模**（含 ASCII），替换现有 Montserrat 14/24，
> 覆盖当前 UI + 全部规划游戏名 + 常用界面词，共 **161 个汉字 + 3 个符号**。
> 预计 Flash 占用：14px @ bpp4 ≈ 110B/字 → 161 字约 **18KB**（裕量 778KB，毫无压力）。

## 1. 网页参数设置

| 字段 | 填什么 | 说明 |
| --- | --- | --- |
| Name | `lv_font_cn_14` | 生成的字体变量名，代码里按此名引用 |
| Size | `14` | 唯一字号，与当前正文一致 |
| Bpp | `4` | 16 级灰度抗锯齿；圆屏小字务必用 4，勿选 1/2（锯齿明显） |
| TTF | `C:\Windows\Fonts\simhei.ttf`（黑体） | ⚠️ 雅黑 `msyh.ttc` 和宋体 `simsun.ttc` 是 TTC 合集，网页工具**解析不了**；黑体是单文件 TTF，笔画均匀适合小屏。若追求开源授权可换"思源黑体 Regular" |
| Range | `0x20-0x7F` | 完整 ASCII（数字/字母/常用符号），使英文界面与中文同字体 |
| Symbols | 见下方"字符集"整段复制 | 所有汉字 + ℃ ° ： |

输出格式保持默认（LVGL C 文件），点 **Convert** 下载 `lv_font_cn_14.c`。

## 3. 生成后接入步骤（我来执行）

1. `lv_font_cn_14.c` 放入 `LVGL_BSP/font/`，加入 Keil（LVGL_BSP 组）
2. 新建 `lv_font_cn.h`：`LV_FONT_DECLARE(lv_font_cn_14);`
3. `lv_conf.h`：
   - `LV_FONT_DEFAULT` → `&lv_font_cn_14`
   - `LV_FONT_MONTSERRAT_14` 置 0；`_24` 按实际情况（DEMO 组 demo_sensor.c 在用则保留）
   - `LV_USE_FONT_COMPRESSED` 置 1（在线工具默认压缩输出，否则黑屏）
   - `LV_USE_FONT_SUBPX` 置 1（生成时带亚像素/`--lcd` 则必须，否则文字不绘制）
4. 启动器等原 24px 大字处改为 `lv_font_cn_14`
   （视觉上变小；如需大字效果，可用 `lv_obj_set_style_transform_zoom(label, 512, 0)` 做 2 倍缩放，代价是像素感）
5. 字符串替换为中文，**含中文的 .c 文件必须保存为 UTF-8 with BOM**
   （Keil AC5 无 BOM 会按 GBK 解释，屏幕显示乱码）

## 4. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 网页上传 TTF 报错 | 用了 .ttc 合集，换 simhei.ttf 或思源黑体 .otf/.ttf |
| 屏幕显示方块 | 该字不在 Symbols 里，把缺字追加后重新生成替换 .c |
| 屏幕显示乱码（全部中文） | 源文件不是 UTF-8 with BOM，用编辑器另存为带 BOM |
| 中文显示但英文变了 | 正常现象：英文数字也来自新字模，风格统一 |
| 编译报错 `struct "_lv_font_t" has no field "static_bitmap"` | 在线工具按新版 LVGL 生成，8.3 的 `lv_font_t` 无此字段，删除 `.static_bitmap = 0,` 一行即可 |
| 编译报错找不到 `lvgl/lvgl.h` | Keil AC5 不支持 `__has_include`，把字模头部的包含判断块整体改为 `#include "lvgl.h"` |
| **烧录后屏幕全黑，但蜂鸣/摇杆/编码器正常** | 字模是压缩格式（`.bitmap_format = 1`）而 `LV_USE_FONT_COMPRESSED = 0`，每个字符位图都返回 NULL → 全部跳过绘制。该宏置 1 即可；或重新生成时取消 Compress 并把宏改回 0 |
| 文字一律不绘制（图形正常） | 字模带亚像素（`--lcd`，`.subpx = LV_FONT_SUBPX_HOR`）而 `LV_USE_FONT_SUBPX = 0`；置 1 |
| 中文/英文有红蓝彩边 | 亚像素方向与屏幕 RGB 排列不匹配，翻转 `lv_conf.h` 的 `LV_FONT_SUBPX_BGR`（0↔1） |
| **Keil 报 `missing closing quote` 且字符串显示成 `灏忔亹榫欒烦璺?`** | 文件丢了 UTF-8 BOM（某些编辑/保存动作会剥掉 BOM），Keil 按 GBK 解释导致中文字符串被截断。重新另存为 **UTF-8 with BOM** 即可；**每次改完带中文的字符串都要复查 BOM** |
