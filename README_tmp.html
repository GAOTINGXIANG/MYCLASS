MYCLASS_MX —— STM32F407 圆屏多功能掌机

嵌入式系统课程设计项目。以 STM32F407VGT6 为平台，在 240×240 圆形 IPS 屏上实现了一套 带环形菜单、传感器仪表和 19 个可玩小游戏 的图形化交互终端。

2. 硬件基础

2.1 主控与最小系统

  • STM32F407VGT6：Cortex-M4F 内核，单精度硬件 FPU + DSP 指令，最高 168 MHz； 1 MB Flash、192 KB SRAM（其中 64 KB CCM 只能被 CPU 访问，DMA 不可用），LQFP100 封装。
  • 时钟源：外部 8 MHz 晶振（HSE）作为 PLL 输入，最终 168 MHz 系统时钟（见 4.1）。
  • 下载调试：SWD（SWDIO/SWCLK）两线调试；板载 RESET、BOOT0、KEY 按键。
  • 供电：3.3 V 逻辑，USB 供电；外设模块（超声波、磁力计、温湿度）均为 3.3/5 V 兼容。

2.2 板卡与外设实物

正面（带芯片） 正面（去芯片） 背面

正面：STM32F407 核心板（TF 卡槽、USB、彩色排针、晶振）+ 圆形 GC9A01 屏（模块丝印 LED SCK SDA A0 RES CS GND VCC）+ 五针模拟摇杆 + HC-SR04 超声波模块。

背面：洞洞板走线，固定了 HMC5883L 磁力计模块（I²C）、TF 卡转接板等。

TF 卡槽与 TF 卡模块在本工程中未使用（未启用 SDIO/FATFS），仅作为硬件资源保留。 DEMO/ 目录是开发过程中的单外设验证例程，已被 APP/ 的正式应用取代。

4. 涉及的单片机知识点

4.1 时钟树与 PLL

Core/Src/main.c 的 SystemClock_Config()：

  • HSE = 8 MHz → PLLM = 4 → 2 MHz 比较频率 → PLLN = 168 → VCO 336 MHz → PLLP = 2 → SYSCLK = 168 MHz，PLLQ = 4 → 84 MHz（USB/SDIO 用）。
  • AHB 不分频（168 MHz），APB1 四分频（42 MHz），APB2 二分频（84 MHz）。
  • PWR_REGULATOR_VOLTAGE_SCALE1 + FLASH_LATENCY_5：168 MHz 下必须提高内核电压等级并插入 5 个 Flash 等待周期，否则取指错误。

注意：APB1 上的定时器在分频系数≠1 时，定时器时钟会被硬件 ×2，因此 TIM4/TIM5 实际 计数时钟是 84 MHz（这一点直接决定了下面两个定时器的分频值）。

4.2 GPIO 的四种用法

  • 推挽输出：LCD 背光/复位/片选/DC、蜂鸣器、6 颗 LED。
  • 上拉输入：4 个按键、编码器按压、摇杆按压——按键接地，按下读到低电平。
  • 复用推挽：SPI1 的 SCK/MOSI（GPIO_MODE_AF_PP + GPIO_AF5_SPI1）； 定时器输入捕获 PB7（GPIO_AF2_TIM4）。
  • 复用开漏：I2C2 的 SCL/SDA（GPIO_MODE_AF_OD + GPIO_AF4_I2C2），依赖外部上拉； DHT11 数据线用开漏输出 + 内部上拉，写 1 即释放总线，同时 IDR 仍能读出真实电平。

4.3 按键消抖与“按下沿”事件

HARDWARE/keys.c 不是简单阻塞延时，而是基于时间戳的状态机：

  1. keys_update() 采样 6 个键，电平变化时记录 change_tick；
  2. 电平稳定超过 KEYS_DEBOUNCE_MS = 20 ms 才更新“稳定状态”；
  3. 稳定状态由 0→1 时置位 edges 位图；keys_scan() 返回并清除该位图，实现按下沿一次性 事件，避免长按重复触发。

编码器按压键在 keys.c 中覆盖了 lv_port_indev.c 的弱函数 lv_port_encoder_key()，保证 “物理按键”和“LVGL 输入设备”读到的是同一份消抖后的状态。

4.4 旋转编码器：定时器编码器接口（TIM5）

Core/Src/tim.c：TIM5 工作在 TIM_ENCODERMODE_TI12（A/B 两相四倍频计数）， 32 位计数范围（Period = 0xFFFFFFFF），输入滤波器 ICFilter = 8（抑制旋转抖动）。

HARDWARE/encoder.c 用无符号做差再转有符号读取增量：delta = (int32_t)(now - last)， 计数器 32 位回绕时结果依然正确。上位逻辑再按 ENC_DETENT = 4 换算成“档”（一格）， 菜单里一格 = 移动一项。

4.5 输入捕获测距（TIM4 + HC-SR04）

HARDWARE/hcsr04.c：

  • 分频 83 → 计数时钟 1 MHz，每计数 = 1 µs（ARR = 65535，16 位）。
  • 流程：配置上升沿捕获 → 清标志/清计数器 → 启动捕获 → 发 12 µs Trig 脉冲 → 轮询 TIM_FLAG_CC2 等上升沿 → 改成下降沿捕获 → 再等一次 → t_end - t_start 即回波宽度。
  • 换算：距离(cm) = 脉宽(µs) / 58（声速 343 m/s，往返各一次）。
  • 超时用 DWT 周期计数器（DWT->CYCCNT）而不是 SysTick，因此可以在任意任务中安全使用， 不会被调度器打断逻辑。

4.6 ADC + DMA：双轴摇杆

Core/Src/adc.c：ADC1 双通道规则组扫描（IN11 / IN13），12 位分辨率、连续转换、 采样时间 84 周期，DMA 循环模式（DMA2_Stream0 / Channel 0，半字对齐）， 转换结果直接写入 joy_adc_buf[2]，CPU 无需参与。

HARDWARE/joystick.c 再做了三件事：

  1. 上电自校准：连续 16 次采样求中点，避免电位器个体差异；
  2. 归一化：(raw - center) * 1000 / 2048 → −1000~+1000；
  3. 带阈值的方向判定：X/Y 独立比较阈值得到位掩码，支持 8 方向；并提供 JOY_XY_SWAP 等宏修正装配方向。

4.7 I²C 读写磁力计（HMC5883L）

HARDWARE/hmc5883l.c：I2C2 100 kHz、7 位地址 0x1E（HAL 需左移成 8 位）。

  • 上电先读 ID 寄存器（0x0A 起 3 字节，应为 H 4 3）做器件自检；
  • 配置 A = 0x70（8 次平均、15 Hz、正常测量），配置 B = 0x20（增益 1090 LSB/Gauss， ±1.3 Ga），模式 = 0x00（连续测量）；
  • 数据寄存器顺序是 X, Z, Y（不是 X, Y, Z），读 6 字节后按高低字节拼接；
  • 航向角：heading = atan2f(x, y) * 180/π，再叠加磁偏角补偿 （宏 HMC5883L_MAG_DECL_DEG10，按当地磁偏角调整）并归一化到 0~360°；
  • 校准采用 min-max 法：全方位旋转记录各轴极值，中值作“硬铁偏移”，半幅作比例因子， 旋转不充分（半幅 < 100 LSB）时拒绝生效。

4.8 单总线时序（DHT11）

HARDWARE/dht11.c 用 DWT 实现微秒级时序（不开定时器也能量 µs）：

  • 主机拉低 ≥18 ms → 释放 30 µs；
  • 等待传感器应答（低 80 µs / 高 80 µs / 再低）；
  • 连续读 40 位：每位先 50 µs 低电平，再判高电平宽度——>40 µs 为 1，否则为 0；
  • 5 字节中前 4 字节之和的低 8 位等于第 5 字节才算校验通过。

4.9 DMA + SPI 刷屏

Core/Src/spi.c：SPI1 主机、1-line 单向、8 位、CPOL=0 / CPHA=1Edge（模式 0）、软件 NSS， 预分频 4 → 21 MHz（APB2 = 84 MHz）。

HARDWARE/lcd_spi.c 用 HAL_SPI_Transmit_DMA 发送像素流，DMA = DMA2_Stream3 / Channel 3， 内存→外设、字节对齐、普通模式；传输完成中断里 HAL_SPI_TxCpltCallback() 拉高 CS 并 lv_disp_flush_ready() 通知 LVGL 这块缓冲已刷完。

关键约束：DMA 只能访问主 SRAM，所以两块显示缓冲必须放在普通 SRAM，不能放 CCM。

4.10 FreeRTOS 任务划分

Core/Src/freertos.c：

任务 栈 优先级 职责
LVGL_TASK 4 KB Normal7（最高） lv_init → 显示/输入移植 → 启动器，循环 lv_tick_inc(5) + lv_timer_handler() + osDelay(5)
defaultTask 512 B Normal 空转占位
sensor_task 1 KB Low sys_sensor_poll() 每 20 ms 一轮：DHT11（1 s）、HC-SR04（250 ms，游戏中 70 ms）
notify_task 512 B Low1 从消息队列取声光命令并播放

设计要点：

  • 阻塞型传感器隔离：DHT11 起始信号要拉低 18 ms、超声波要等回波，若放在 UI 任务里会卡住 刷新；因此放进独立低优先级任务，结果写入全局 g_sensor，UI 只读快照。
  • 时基：LV_TICK_CUSTOM = 0，由 LVGL 任务每 5 ms 手动 lv_tick_inc(5)，避免与 SysTick/FreeRTOS 时基冲突。
  • 声光服务化：LED 与蜂鸣器由 notify_task 独占，其他任务只发命令（osMessageQueueNew(8, ...)）， 避免多任务同时操作同一 GPIO 造成“串音/闪灯错乱”。

4.11 LVGL 移植：显示与输入

  • 显示：双部分缓冲（每块 240×40 像素 = 19.2 KB，两块 38.4 KB）， flush_cb 里设窗口（CASET/RASET/RAMWR 由 gc9a01_set_window() 完成）后启动 DMA， 渲染与传输可并行；LV_COLOR_DEPTH = 16（RGB565）。
  • 输入：注册 编码器（encoder_delta() → LV_INDEV_STATE_PRESSED/RELEASED 滚动）、 按键（KEY2/KEY3/KEY4/摇杆 → LV_KEY_ENTER/PREV/NEXT/ESC）、 摇杆（方向 → LV_KEY_UP/DOWN/LEFT/RIGHT）。
  • 内存：LV_MEM_SIZE = 24 KB，因此应用层大量采用“整屏 canvas 自绘”策略（见 4.12）。

4.12 圆屏 UI 的两条硬约束

  1. 可视区：240×240 圆屏圆心 (120,120)，四角不可见，可用内接正方形约 (35,35)–(205,205)。 所有游戏/仪表的活动区都限制在该范围内。
  2. 对象数：LVGL 每个对象都有额外开销，24 KB 堆顶不住几十个控件。 游戏统一使用 1 个 lv_obj_create 全屏对象 + LV_EVENT_DRAW_MAIN 里用 lv_draw_rect() / lv_draw_line() 直接绘制，只用 1~2 个 lv_label 显示分数， 退出时 lv_obj_clean() 全部回收。

4.13 中文字模（4bpp 亚像素 + 压缩 + 稀疏表）

LVGL_BSP/lv_font_cn_14.c 由在线字体转换工具生成：

  • --bpp 4 --size 14 --lcd --use-color-info --range 32-127，即 ASCII 用 range 0（95 字）， 中文用稀疏 cmap（unicode_list 存 codepoint - 176，list_length = 296）；
  • --lcd 生成亚像素字模，需 LV_USE_FONT_SUBPX = 1；压缩位图需 LV_USE_FONT_COMPRESSED = 1； LV_FONT_SUBPX_BGR 控制红蓝彩边（0 = RGB）；
  • LV_FONT_DEFAULT = &lv_font_cn_14，全局默认中文字体，缺字会显示方块（见 DOC/中文字模生成指南.md）。

5.1 启动器框架

APP/app_launcher.h 定义统一生命周期接口：

typedef struct {
    const char *name;   /* 菜单显示名（中文） */
    void (*enter)(void);/* 进入：建对象 + 建 lv_timer */
    void (*exit)(void); /* 退出：删自己的 lv_timer */
} app_t;
  • app_register() 注册主菜单项，app_register_game() 注册游戏子菜单项；
  • 菜单是半径 80 的圆环，中心大字显示当前选中项；
  • 条目 ≤ 7 时按 360°/n 均匀排布；> 7 时切换为 7 个固定槽位（间隔 36°）的滚动窗口， 只更新文字，避免 19 个游戏挤成一圈；
  • 输入约定：编码器旋转 / 摇杆左右 = 切换，ENCODER_KEY / JS_KEY = 确认， KEY1 归启动器所有 = 返回上一级（应用不得消费），切换与确认都触发 NOTIFY_MARQUEE_ONCE 做声光反馈。

游戏层公共设计

  • 每个游戏 1 个 lv_timer（20~30 ms 一拍）驱动“逻辑 + 重绘”，退出时删除；
  • 动作类游戏有生命值（新做的 9 款为 3 命，早期贪吃蛇/打砖块为 6 命），用 game_common 的 game_lives_set/dec 点亮 6 颗 LED 中的前 n 颗，扣命时蜂鸣提醒；game_lives_clear() 在退出时熄灭； 棋盘类游戏则以分数/胜负为目标，结束后按 ENC/JS/KEY2 重开；
  • 撞机/撞障碍后给 20 拍左右无敌时间，避免一次碰撞连扣多条命；
  • 所有绘制都在 LV_EVENT_DRAW_MAIN 里做，坐标限制在圆屏内接正方形内。

5.4 声光通知服务

APP/sys_notify.h：8 种命令（短鸣、长鸣、成功、错误、流水灯、生命值、单次流水灯、停止）， 由 notify_send() 投递到队列，notify_task 异步执行；新命令立即打断旧效果。 音效总开关 sys_notify_sound_set() 默认开启，关闭后只做灯光不出声（不掉电保存）。

5.5 传感器数据分发

APP/sys_sensor.c 统一在 sensor_task 中轮询，写入 g_sensor（温度/湿度/距离/时间戳/有效标志）：

  • DHT11 每 1 s 一次（器件最小间隔）；
  • HC-SR04 常规 250 ms 一次，进入小恐龙/打地鼠时通过 sys_sensor_set_fast(1) 切到 70 ms 快采样（HC-SR04 建议 ≥60 ms，避免上一发回波串扰）；
  • 应用层（雷达/温湿度/小恐龙/打地鼠）只读 g_sensor，不直接操作硬件。

6. 编译与运行

  1. 用 Keil MDK 打开 MDK-ARM/MYCLASS_MX.uvprojx，目标 MYCLASS_MX，编译器 AC5，C99 模式；
  2. 直接 Build → Download 到板子；
  3. 上电后进入圆环菜单，KEY1 随时返回上一级。

注意事项：

  • 含中文的 .c/.h 必须保存为 UTF-8 with BOM，否则 AC5 按 GBK 解析会出现 missing closing quote；
  • lv_conf.h 中 LV_USE_FONT_COMPRESSED、LV_USE_FONT_SUBPX 必须为 1，否则文字不显示；
  • 字模只能整颗重新生成替换，不要手工修改字模表（三张表必须严格对齐）。

7. 已知限制与可扩展方向

  • 圆屏四角不可见，界面设计需留安全边距；
  • LVGL 堆仅 24 KB，复杂界面需改为 canvas 自绘或增大 LV_MEM_SIZE；
  • 字模为固定 296 个中文，新增文案需同步重新生成字模；
  • TF 卡、USB、串口等外设尚未启用，可作为后续扩展（如存档分数、串口调试日志）。
